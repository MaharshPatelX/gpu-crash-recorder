# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-08-30

Initial public beta.

- Added hotkey-controlled, system-wide diagnostic sessions.
- Added AMD ADLX GPU telemetry and PresentMon frame capture.
- Added process, system, Windows Event Log, hardware inventory, and crash-artifact collectors.
- Added crash-safe SQLite storage and offline HTML/CSV/JSON reports.
- Added bookmarks, focused crash windows, interrupted-session recovery, and evidence-based findings.
- Corrected PresentMon process-ID compatibility, historical WER filtering, and LiveKernelEvent 141 detection after validation with a real graphics-engine hang.
