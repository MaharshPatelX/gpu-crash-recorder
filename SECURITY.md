# Security and privacy

Please report security vulnerabilities through GitHub's private vulnerability reporting feature instead of opening a public issue. Include the affected version and enough detail to reproduce the problem, but do not attach a real diagnostic session or crash dump unless it has been sanitized.

GPU Crash Recorder does not upload reports. A generated session can still contain sensitive local information, including process names and paths, hardware identifiers, Windows event contents, and fragments of application memory inside dump files. Users should inspect and redact reports before sharing them.

Only the latest release is supported while the project is in beta.
